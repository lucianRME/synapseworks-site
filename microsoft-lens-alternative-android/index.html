RME PDF Scanner · Android guide

A Private Microsoft Lens Alternative for Android

Microsoft has retired Microsoft Lens, formerly Office Lens. Android users who want a local-first document scanner can use RME to scan documents, recognize text on-device, create searchable PDFs and keep a searchable library without an RME account.

Why Android users are looking for another scanner

Microsoft says Lens was removed from app stores on 9 February 2026 and stopped creating new scans after 9 March 2026. Previous scans can remain accessible when Lens stays installed and the user is signed in to the last active account. Read Microsoft’s retirement notice for its current guidance.

RME is an independent Android app published by SynapseWorks. It is not an official Microsoft Lens replacement and is not affiliated with, endorsed by or partnered with Microsoft.

What RME offers

RME is a private document scanner for Android with no ads, no RME account, no RME analytics or tracking, and no RME cloud backend. The RME app itself requests neither INTERNET nor ACCESS_NETWORK_STATE. Scanning, document editing, OCR, library search and PDF generation are handled on-device.

Latin OCR is built in and available offline. Chinese, Japanese, Korean and Devanagari OCR use optional models delivered by Google Play services. Additional OCR models may be downloaded by Google Play services. Document recognition runs on-device. Learn more in the on-device and offline OCR guide.

You can scan or import PDFs, review and correct OCR text, create searchable PDFs, search recognized text across your library, organize documents in folders and subfolders, and create a portable backup for a new phone. RME’s Android source is also available to inspect in the open-source scanner guide.

How to move your existing Microsoft Lens scans to RME

RME’s guided Move from another scanner workflow includes Microsoft Lens. It works with standard PDFs and supported images; it does not read the Lens database or connect to a Microsoft account.

Option A: Share or export from Microsoft Lens

  1. In Microsoft Lens, open an existing scan and use its share or PDF export action.
  2. Choose RME from Android’s share sheet.
  3. Review the files in RME, then confirm the import.

Option B: Import PDFs you already exported

  1. In RME, open Move from another scanner and choose Select files.
  2. Use Android’s system file picker to select the exported PDFs.
  3. Review the files and confirm the import.

About OneDrive: if OneDrive is available as a location in Android’s system document picker, you can select files from it there. This is standard Android file access, not direct OneDrive integration, a Microsoft Graph or OneDrive API connection, or Microsoft account import.

A local-first Office Lens alternative

For people searching for an Office Lens alternative on Android, RME focuses on document ownership: files you save to RME stay in its private on-device library until you export, back up or share them. RME does not provide proprietary cloud sync. Its optional encrypted portable backup uses a password you choose and can be restored on another phone.

Read the RME Privacy Policy for the precise boundary between RME’s local processing, user-chosen destinations and Google-provided components.
