Chrome Extension Privacy

Submit Guard — Privacy Policy

Last updated: 2026-03-16

Submit Guard does not collect, transmit, sell, or share personal data.

All processing happens locally in your browser.

Only configuration data is stored locally (no form contents are stored).

Summary

Submit Guard does not collect, sell, or share user data. The extension is designed to help you confirm risky form submissions before they are sent.

Data Processing

The extension may inspect page content locally to detect risky phrases and to decide when to show the confirmation dialog. This inspection happens only in your browser.

Page content is not transmitted off-device and is not stored as user content.

What Is Stored

Only configuration data is stored locally in chrome.storage.local. No form contents are stored.

  • Per-site enablement settings.
  • Mode selections.
  • Your configured risky phrase list.
  • Local counters used by the extension.

Third Parties

None. There are no third-party analytics, no remote code, and no ads.

Permissions Explanation

  • storage: save settings locally.
  • activeTab: identify the current site when you toggle Submit Guard for that site.
  • scripting: inject the guard script only on sites that you enable.

User Controls

You can disable Submit Guard per site at any time. If you uninstall the extension, all locally stored settings are removed with it.
