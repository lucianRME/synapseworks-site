# Product preview sources

Checked 20 October 2026. These are web-sized copies of existing public assets,
resized proportionally and encoded as WebP. No interface content was changed,
retouched, cropped, or invented. The 640px and 960px variants are used by `srcset`.

- `rme-tools-*`: approved `assets/play-store/screenshots/phone/04-pdf-tools.png`
  from the RME PDF Scanner repository, 1264 × 1264. The adjacent store-asset
  README identifies the set as finalized v1.7.0 marketing assets. It contains
  the actual app Tools screen and is published on the
  [official Google Play listing](https://play.google.com/store/apps/details?id=org.synapseworks.pageharbor).
- `submit-guard-*`: 1280 × 800 popup screenshot from the
  [official Chrome Web Store listing](https://chromewebstore.google.com/detail/submit-guard-confirm-before-submit/egplmjbdpaffiejoiihpgcndmlkbagjg).
  [Published image](https://lh3.googleusercontent.com/MH8_HaRn33V6WrXz0oqKgAIrKgCcaL6viGeBKBVBEQmXxKhPmK5tjMzTmU6NQDAAJB-r-VD12VO1ucoGY_QZZ-usYEk=s1280-w1280-h800).
  It shows settings for public `www.google.com`, without form contents or personal data.
  Source SHA-256: `90d0e714cde804485050eea38fe39e8498b5922456a0f2034956d9744c4775da`.

The published Submit Guard set does not show its confirmation dialog. Current
raw RME screenshots are also not available in this site; use the approved store
composition until suitable current captures are supplied. Published Jira images

All four products have public installation listings. Jira development status
remains early-stage; that status does not mean the products are unavailable.
