# Navigation icons

Six SVGs from [Phosphor Icons Core](https://github.com/phosphor-icons/core),
under the MIT license included in `LICENSE.txt`.

Source commit: `2b75f3ad12b420c9504ef05df8d2564a28f8500e`.

Product symbols use the duotone weight: scan, shield-check, list-checks, and
flow-arrow. The caret and arrow use the bold weight. Glyph paths are unchanged;
the inherited fill is set to the existing SynapseWorks teal `#0f766e`.
These are navigation symbols, not product logos or third-party endorsements.
No icon library runtime, font, or external CDN is required.
