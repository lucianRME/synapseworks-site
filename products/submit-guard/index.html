Chrome extension

Submit Guard

Submit Guard adds a confirmation step before form submissions on sites you enable, reducing accidental sends in browser workflows.

Install from Chrome Web Store Featured Privacy details Support
Browser tools · Terms · Cookie Policy

Privacy model

Architecture: Local-only Chrome extension. It does not use a SynapseWorks backend.

Accounts: No SynapseWorks account is required.

Storage: Settings are stored locally in chrome.storage.local.

Form content: Form contents are not stored or transmitted by the extension.

What it does

  • Standard mode confirms native HTML form submissions.
  • Advanced mode can guard submit-like clicks in modern web apps when enabled.
  • Per-site controls let you choose where the guard runs.
