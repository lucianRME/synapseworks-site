Decision Register for Jira — Documentation

This page provides reviewer-friendly setup and usage steps for Decision Register for Jira on Jira Cloud.

Open Atlassian Marketplace Listing Contact Support

Installation

  1. Sign in to Jira Cloud with a site admin account.
  2. Open the Decision Register for Jira listing in Atlassian Marketplace.
  3. Select Get it now.
  4. Choose the Jira Cloud site where you want to install the app.
  5. Review and approve the requested permissions.
  6. After installation, confirm the app is visible under Apps > Manage apps.

How To Use

  1. Open a Jira issue in a project where the app is enabled.
  2. Find the Decision Register app panel in the issue view under Apps.
  3. Select Add decision and provide the decision details.
  4. Save the entry to link the decision to the current Jira issue.
  5. Return to the same issue panel at any time to review previously recorded decisions.

Data Handling Summary

Architecture: Forge-only app running on Atlassian infrastructure.

External backend: None.

External network egress: None.

Storage: Minimal app configuration or preference data may be stored in Forge storage (storage:app) where applicable.

Troubleshooting

  • App not visible: Confirm installation on the correct Jira Cloud site and verify the project/issue view includes app panels.
  • Cannot save decision: Ensure required fields are completed and the user has permission to edit the issue.
  • Permissions issues: Check Jira project permissions and access roles for affected users.

If the issue persists, contact support@synapseworks.org.
