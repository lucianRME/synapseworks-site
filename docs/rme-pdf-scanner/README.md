# RME: PDF & Document Scanner

RME: PDF & Document Scanner is an open-source, privacy-first Android document scanner published by SynapseWorks. It was formerly known as PageHarbor; the app and its privacy-first principles remain the same.

> **Status:** Version 1.2.0 is available on Google Play. [Get RME PDF Scanner on Google Play](https://play.google.com/store/apps/details?id=org.synapseworks.pageharbor).

## At a glance

- Android application with a minimum supported Android API level of 26.
- Up to 10 pages can be captured in one scanner session.
- Camera scanning is provided through Google ML Kit Document Scanner.
- Gallery import, normal PDF export, JPEG page export, Android Sharesheet sharing, bundled Latin-script OCR, explicit Copy Text, and local searchable-PDF generation are supported.
- Export destinations are selected by the user through Android’s Storage Access Framework (SAF).
- RME PDF Scanner has no account, ads, tracking or analytics, proprietary backend, or persistent document library.
