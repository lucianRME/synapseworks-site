# Getting started

[Get RME PDF Scanner on Google Play](https://play.google.com/store/apps/details?id=org.synapseworks.pageharbor&utm_source=synapseworks&utm_medium=website&utm_campaign=rme_v1_6) for an Android device running API level 26 or later.

## Start a document

1. Scan paper with the Google ML Kit scanner, choose images or PDFs with Android's file picker, or share supported files into RME from another app.
2. Review pages, reorder or rotate them, remove pages you do not need, and apply a document filter if useful. Interactive paper capture supports up to 20 pages; ordinary file import and migration can preserve longer documents within RME's safety limits.
3. Choose **Save to RME** if you want the document in RME's private on-device library. Unsaved work is not silently kept after process death.
4. Reopen a saved document to edit it, run OCR, export it, or share it.

Imported source files remain with the provider you selected. Saving to RME creates a private copy; removing that copy does not delete the source.

## Find and combine saved documents

Rename saved documents, use folders and subfolders, sort the library, and search titles and recognized text across all documents. Search results can show a matching snippet and open the matching page. Select saved documents to merge them in a chosen order, or extract selected pages into a new document.

## OCR and export

Latin OCR is built in. Chinese, Japanese, Korean, and Devanagari OCR use optional models delivered by Google Play services; document recognition runs on-device. Review, correct, copy, or re-run recognized text, and batch-recognize selected documents. For an exported searchable PDF, RME adds a text layer based on the effective OCR result; check important text against the scanned page.

## Move and protect your library

Use **Move from another scanner** to review and import standard PDFs or supported images exported or shared from another scanner. Use **Backup & restore** to create a complete portable backup, optionally protect it with a password, and restore it on another phone. Android automatic backup remains disabled; these operations run only when you choose them.

Save standard or searchable PDFs and individual JPEG pages through Android's system file picker. To share a PDF, choose a receiving app through Android's Sharesheet. Your selected provider or receiving app handles the exported file under its own policies.

See the [full workflow](workflow.md) and [privacy policy](https://synapseworks.org/rme-pdf-scanner/privacy/) for storage and third-party details.
