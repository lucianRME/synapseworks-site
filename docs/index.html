Product docs for Jira teams

SynapseWorks provides two Forge-first products: Synapse and Decision Register for Jira. This page summarizes installation, scopes, and troubleshooting guidance without adding runtime dependencies.

Open Synapse demo Synapse Decision Register

Products overview

  • Synapse: Jira Forge app that sends Jira issue context to a scoped Azure backend and returns results to Forge and Jira.
  • Decision Register for Jira: Forge-only with no external backend or network egress; data stays within Atlassian.

Install links

  • Synapse product page: /apps/synapse
  • Decision Register product page: /apps/decision-register
  • Synapse demo: https://synapseworks.org/synapse/demo

Scopes summary

Synapse: Uses Forge appUserToken and scoped permissions. No Jira credentials are stored. Processing uses a scoped SynapseWorks Azure backend.

Decision Register for Jira: Forge-only with no external backend or network egress; data stays within Atlassian. Limited user preferences may be stored via Forge storage (storage:app).

Troubleshooting

  • Confirm the app is installed and enabled for the correct Jira site and project.
  • Capture the Jira issue key, timestamp, and expected vs. actual behavior.
  • For Synapse, requests are monitored and fail safely with clear errors when limits are reached.
  • Do not share credentials, tokens, session cookies, or MFA codes with support.
