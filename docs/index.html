Product docs for Jira teams

SynapseWorks provides two Forge-native products that run on Atlassian: Synapse Forge and Decision Register for Jira. Canonical product documentation is hosted on GitBook.

Synapse docs Decision Register docs Trust & Security

Products overview

  • Synapse: Jira Forge app running on Atlassian with no external backend, no external storage, and no external network egress.
  • Decision Register for Jira: Forge-only app running on Atlassian with no external backend, no external storage, and no external network egress.

Install links

  • Synapse product page: /apps/synapse
  • Decision Register product page: /apps/decision-register

Scopes summary

Synapse: Uses Forge appUserToken and scoped permissions. No Jira credentials, personal access tokens, or shared secrets are stored.

Decision Register for Jira: Forge-only with limited user preferences in Forge storage (storage:app). No external backend, no external storage, and no external network egress.

Troubleshooting

  • Confirm the app is installed and enabled for the correct Jira site and project.
  • Capture the Jira issue key, timestamp, and expected vs. actual behavior.
  • For Synapse, requests are monitored and fail safely with clear errors when limits are reached.
  • Do not share credentials, tokens, session cookies, or MFA codes with support.
