# PageHarbor

PageHarbor is an open-source, privacy-first Android document scanner published by SynapseWorks.

> **Status:** PageHarbor is available on Google Play. [Get PageHarbor on Google Play](https://play.google.com/store/apps/details?id=org.synapseworks.pageharbor).

## At a glance

- Android application with a minimum supported Android API level of 26.
- Up to 10 pages can be captured in one scanner session.
- Camera scanning is provided through Google ML Kit Document Scanner.
- Gallery import, normal PDF export, JPEG page export, Android Sharesheet sharing, bundled Latin-script OCR, explicit Copy Text, and local searchable-PDF generation are supported.
- Export destinations are selected by the user through Android’s Storage Access Framework (SAF).
- PageHarbor has no account, ads, PageHarbor tracking or analytics, backend, or persistent document library.
