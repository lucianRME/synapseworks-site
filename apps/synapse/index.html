Product

Synapse

Synapse is a Jira Forge app that helps delivery teams generate structured outputs and automation-ready artifacts directly inside Jira.

Get support Install from Atlassian Marketplace
Privacy Policy · Security

Key capabilities

  • Generate consistent, delivery-ready artifacts from Jira issue context.
  • Keep workflows inside Jira with Forge-native user experience.
  • Support enterprise delivery practices with auditable flows.
  • Return results directly to Forge and Jira without credential storage.

Data handling summary

Architecture: Atlassian Forge app with scoped processing through a SynapseWorks Azure backend.

What is processed: Jira issue context required to generate outputs. No transcript text is processed.

Auth model: Forge appUserToken and scoped permissions. No Jira credentials or personal access tokens are stored.

Flow: Jira → Forge → SynapseWorks Azure backend → Forge/Jira.
