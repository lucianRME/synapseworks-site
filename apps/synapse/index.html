Product

Synapse

Synapse is a Jira Forge app that helps delivery teams generate structured outputs and automation-ready artifacts directly inside Jira.

Install from Atlassian Marketplace Documentation Support
FAQ · Privacy Policy · Security

Key capabilities

  • Generate consistent, delivery-ready artifacts from Jira issue context.
  • Keep workflows inside Jira with Forge-native user experience.
  • Support enterprise delivery practices with auditable flows.

Data handling summary

Architecture: Atlassian Forge app with a scoped backend service via Forge Remote.

What is processed: In Jira (Forge Issue Panel), Synapse generates from Jira issue context. Transcript processing is available only in Synapse SaaS deployments (if enabled).

Auth model: Forge appUserToken with scopes read:jira-work, write:jira-work, and read:app-user-token. No Jira credentials or personal access tokens are stored.

Flow: Jira → Forge → scoped backend service via Forge Remote → Forge/Jira.

Forge vs SaaS

  • Inside Jira (Forge): issue-context generation, refine editor, dry-run validation, and create subtasks where enabled.
  • Outside Jira (SaaS, deployment-dependent): transcript ingestion, review workflow, and idempotent Jira sync.
