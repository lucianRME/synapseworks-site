Synapse for Jira

Early-stage · Available on Atlassian Marketplace

Synapse for Jira is a Forge-native app that helps delivery teams generate structured outputs and automation-ready artifacts directly inside Jira, running on Atlassian infrastructure.

Key capabilities Data handling summary Runs on Atlassian

Key capabilities

  • Generate consistent, delivery-ready artifacts from Jira issue context.
  • Keep workflows inside Jira with Forge-native user experience.
  • Support enterprise delivery practices with auditable flows.

Data handling summary

Architecture: Fully Forge-native runtime on Atlassian.

What is processed: Jira issue context required to generate structured outputs inside Jira.

External services and storage: None. No external backend, no external storage, and no external network egress.

Auth model: Forge appUserToken with scopes read:jira-work, write:jira-work, and read:app-user-token. No Jira credentials, personal access tokens, or shared secrets are stored.

Flow: Jira → Atlassian Forge runtime → Jira.

Runs on Atlassian

  • Synapse Forge runs within Atlassian Forge context for Jira usage.
  • No external backend services, no external storage, and no shared secrets or PATs are required.
  • Trust details: GitBook Trust & Security.
