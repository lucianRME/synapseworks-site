Decision Register for Jira

Decision Register for Jira is Forge-only with no external backend, no external storage, and no external network egress.

Install from Atlassian Marketplace Read guide Support
FAQ · Privacy Policy · Security · Trust & Security

Key capabilities

  • Detects decision changes for estimate, priority, scope/sprint, reopen, assignee, due date, and fix version.
  • Exports results to CSV, with a copy-to-clipboard fallback when direct download is unavailable.
  • Retries Jira API calls on rate limits and server errors, with warnings when results are partial.
  • Maintains a read-only access pattern with limited per-user preferences in Forge storage.

Data handling summary

Architecture: Forge-only app that runs entirely on Atlassian infrastructure.

External services: No external backend, no external storage, and no external network egress.

Data use: Read-only access patterns focused on decision and issue context.

Storage: Limited user preferences may be stored via Forge storage (storage:app).
