RME PDF Scanner · Android guide

An open-source document scanner for Android

RME: PDF & Document Scanner publishes its Android application source under the Apache License 2.0. You can inspect how the app handles scans, imported files, saved documents, OCR and exports before choosing whether it fits your workflow.

What you can inspect

The official RME source repository includes the Android app code, privacy documentation and license. Its current workflow lets you scan paper, import multiple images or PDFs, receive supported Android shares, and edit pages. Saved documents live in a private on-device library with folders, search and sorting. You can merge saved documents, extract pages, run Latin-script OCR locally and export standard or searchable PDFs.

Source access makes the implementation and declared permissions reviewable. It also lets contributors report issues with a specific code path. As with any software, source availability alone does not prove that every device or third-party component behaves identically.

Privacy choices visible in the project

RME does not require an account, show ads, run its own tracking or analytics service, or operate a document backend. The app keeps saved documents locally when you explicitly choose to save them. Exports use Android's system picker, so the user chooses a destination; sharing uses Android's Sharesheet.

The current Android configuration declares no INTERNET permission and disables backup of private app data. For the complete data-handling description, including temporary files and deletion, read the RME Privacy Policy.

Know the external components

RME uses Google ML Kit Document Scanner for capture and bundled ML Kit Text Recognition for OCR. Those SDKs are separately licensed; calling RME open source does not make every dependency open source. Google's documented technical diagnostics and possible scanner-resource downloads are also described in the policy. If these boundaries matter to you, review the project's third-party notices alongside the app code.
