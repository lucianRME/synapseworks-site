RME PDF Scanner · Android guide

An open-source document scanner for Android

RME: PDF & Document Scanner publishes its Android application source under the Apache License 2.0. You can inspect how the app handles scans, imported files, saved documents, OCR and exports before choosing whether it fits your workflow.

What you can inspect

The official RME source repository includes the Android app code, privacy documentation and license. Its current workflow lets you scan paper, import or migrate images and PDFs, and edit pages. Saved documents live in a private on-device library with nested folders and full-text search. You can merge or split documents, review and correct multilingual on-device OCR, batch-recognize documents, create searchable PDFs, and make or restore a portable library backup.

Source access makes the implementation and declared permissions reviewable. It also lets contributors report issues with a specific code path. As with any software, source availability alone does not prove that every device or third-party component behaves identically.

Privacy choices visible in the project

RME does not require an account, show ads, run its own tracking or analytics service, or operate a document backend. The app keeps saved documents locally when you explicitly choose to save them. Exports use Android's system picker, so the user chooses a destination; sharing uses Android's Sharesheet.

The current Android configuration requests neither INTERNET nor ACCESS_NETWORK_STATE. Android automatic backup of private app data remains disabled; user-initiated portable backup and restore use files selected through Android's system picker. For the complete data-handling description, read the RME Privacy Policy.

Know the external components

RME uses Google ML Kit Document Scanner, bundled Latin text recognition, and optional Google Play services OCR models for Chinese, Japanese, Korean and Devanagari. Those SDKs are separately licensed; calling RME open source does not make every dependency open source. Additional OCR models may be downloaded by Google Play services; document recognition runs on-device. Google's documented technical diagnostics and possible scanner-resource downloads are described in the policy. Review the project's third-party notices alongside the app code.
